# StyleMe Mobile App Design

This is a code bundle for StyleMe Mobile App Design.

## How to Run

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Open in browser:**
   The app will be available at `http://localhost:5173` (or the port shown in the terminal)

## What This Frontend Shows

StyleMe is a mobile fashion app that helps users manage their wardrobe and get style recommendations. The frontend displays the following screens and features:

### Screens

- **Onboarding Screen**: Welcome screen that introduces users to the app
- **Home Screen**: Main dashboard showing recent clothing items with an "Add Item" button to upload new pieces to the wardrobe
- **Wardrobe Screen**: Displays all clothing items in the user's collection, organized by category
- **Item Details Screen**: Shows detailed information about a selected clothing item, including options to "Complete the Look" or delete the item
- **Recommendation Screen**: Provides style recommendations and outfit suggestions based on selected items

### Features

- **Add Clothing Items**: Users can add new items to their wardrobe through the home screen
- **Browse Wardrobe**: View and organize all clothing items by category
- **Item Management**: View item details, get outfit recommendations, and delete items
- **Bottom Navigation**: Easy navigation between Home, Wardrobe, and Recommendation screens
- **Mobile-First Design**: Responsive mobile app interface optimized for mobile devices

The app uses React, TypeScript, Vite, and Tailwind CSS with Radix UI components for a modern, accessible user interface.
