🧪 STEP 2: TEST
────────────────────────────────────────────────────────────────

  ✓ Check everything is working
  ✓ Download AI model (2GB, first time only)
  ✓ Create test image
  ✓ Remove background
  ✓ Save results to test_output/


🎨 STEP 3: USE WITH YOUR IMAGE
────────────────────────────────────────────────────────────────

Multiple images:
  python batch_processor.py --input ./photos --output ./results
